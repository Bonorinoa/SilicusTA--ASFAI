# L1 · Live walk: the agent builds two courses from its own sources (replayable)

Runs on merged `main` (the PM unblocks this with the sha). You are a teacher who is new to Silicus. **Pick two topics you are
genuinely curious about** and say why in one line each:
- **Course A, in range:** learners aged 6–12, a topic the skill map should cover.
- **Course B, off range:** university or postgraduate learners (the skill map has nothing past 15, so this tests the "no map" path).

## The folder (the whole point is that the owner can replay it)

Everything goes in one small folder, **under 25 MB**:
`/Users/bonorinoa/Hermes/Projects/silicus-private/live-tests/2026-11-<dd>/` (outside git).

```
README.md        how to replay: host command, Node version, sha, browser, the exact clicks/inputs in order

inputs/urls.txt  each URL, the date you fetched it, its licence

exports/         each course's Export file
shots/           screenshots of each step for both courses
run-log.md       time-stamped log: action → what the app showed → time it took; model calls and cost
EXPERIENCE.md    your experience as a first-time teacher (below)
```

**Sources must be open-licensed or your own:** Wikipedia/Wikimedia, OpenStax, NASA, NOAA, Project Gutenberg, government pages, or
documents you write yourself. No paywalled or all-rights-reserved content. Per course use **every source type**: at least one PDF,
one Word file (`.docx`, you may write it), one plain text or Markdown file, pasted notes, and two web links (one that loads, and one
from a site likely to block automatic reading, so the error path shows).

## The walk (local Node host, live model)

Start the host with the worker credential: `SILICUS_WORKER_ENV_FILE=~/.silicus/worker.env` (never read that file). Use
`/Users/bonorinoa/.local/bin/node` (v22.22.3). Drive real Chrome. For each course: the wizard (lesson length, skill-map step:
anchor and connect where it makes sense, skip for B if it offers nothing), sources, your own objectives plus proposals (accept, edit,
drop some, and say why), the AI check, confirm, draft the plan, edit something in it, publish, rehearse with at least 8 student
questions (on-topic, vague, off-topic, "what's your name", "what grade will I get", and one in Spanish), then Export.

## EXPERIENCE.md (about 800–1,200 words, plain language)

What you expected at each step, and what happened. Where you hesitated. Which proposals were good, and which were bad and why.
Whether the plan is one you would actually teach. What the map step did for A, and what the app said for B. Every moment where you
didn't know what was going on (observability). The three best things and the three worst. Rank problems by how much they would
hurt a real teacher. Quote the app's exact text where it matters.
